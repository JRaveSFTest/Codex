# Moderated Interview Guide

Use this guide when evaluating the prototype with developers working inside VS Code.

## Before the Session

- Confirm the participant is comfortable with agentic coding workflows.
- Capture current habits for planning, verification, and approval handling.
- Ask whether they already use AGENTS files, skills, or external connectors.

## Opening Questions

1. What makes you stop trusting an autonomous coding agent?
2. Where do current IDE agents create the most babysitting overhead?
3. Which parts of a task do you want an agent to own outright, and which parts must stay inspectable?

## Task Prompts

- Give the participant one benchmark scenario at a time.
- Start with a baseline run, then repeat with the prototype.
- Ask them to say when:
  - they feel context is missing
  - they want a subagent to be visible
  - an approval prompt feels unnecessary or unclear
  - they would want to pause and resume later

## Observation Checklist

- Did the participant inspect the task plan before edits started?
- Did they understand why context items were included?
- Could they identify which subagent owned which concern?
- Did grouped approvals reduce interruptions or increase anxiety?
- Did status and verification surfaces change when they trusted the prototype?

## Closing Questions

1. Which prototype surface changed your confidence the most?
2. What information was still missing before you would delegate a longer task?
3. Would you trade some raw speed for better verification and resume safety?
4. Which command or panel would you keep if only one shipped first?

## Output Template

- Participant profile
- Scenario
- Baseline outcome
- Prototype outcome
- Trust breakpoints
- Notable quotes
- Highest-value next change
