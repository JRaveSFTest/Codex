# Ubuntu Command Line Glossary

The canonical language for this workspace. Terms are added **after** you can use
them correctly — not when they are first introduced. A short glossary is a
healthy one; it is a record of compressed understanding, not a dictionary to
read.

## Terms

_Empty for now. Lesson 1 introduces `PATH`, the Linux filesystem root, and the
distinction between a binary, an alias, and a shell builtin. Once you use those
correctly — in a question you ask me, or in the Lesson 1 quiz — they get
promoted here with a definition in your own words._

## Ambiguities to resolve as we go

- **"Terminal", "shell", "console", "Bash", "Ubuntu"** are used
  interchangeably in most writing online. In this workspace: the **terminal** is
  the window, the **shell** is the program reading your commands (**Bash**), and
  **Ubuntu** is the operating system underneath. When a distinction matters, the
  lesson will say which one it means.
- **"Directory" vs "folder."** This workspace says *directory*, because that is
  what every Linux tool and error message calls it.
