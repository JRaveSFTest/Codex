You know what you want to do. This sheet is the spelling. Read the left column as "the thing my hands want to type", the right as "what Ubuntu understands".

Six differences that explain most of the rest

  1. PowerShell pipes objects; Bash pipes text. In PowerShell | Where-Object Name -like '*.log' filters real objects with properties. In Bash a pipe carries a stream of bytes, and the tool on the right re-parses it as lines and columns. This is why Bash has so many small text tools — grep, cut, awk, sort — where PowerShell has one object model.
  2. Case matters. README.md and readme.md are two different files on the Linux side.
  3. Flags are terse. One dash plus one letter (-l), or two dashes plus a word (--long). Single letters combine: ls -la is ls -l -a. There is no -Recurse; there is -r, and only if that command happens to have one.
  4. The shell expands wildcards, not the command. rm *.log means Bash replaces *.log with the list of matching filenames before rm runs. If nothing matches, the command sees the literal *.log.
  5. There is no Recycle Bin and no -WhatIf. rm is immediate and permanent. Look before you delete; ls the glob first, then swap ls for rm.
  6. Quoting works the way you already expect. Double quotes expand $VARIABLES, single quotes are literal — same convention as PowerShell. Always quote paths containing spaces: cd "/mnt/c/Program Files".

False friends

Commands that exist in both worlds and mean different things.

Looks likeWhat actually happens in Bash
ls -ForceError. PowerShell-style flags don't exist. You want ls -a.
dirGenuinely runs — Ubuntu ships a dir — but it isn't ls, and nobody uses it. Use ls.
curlThe real curl, with entirely different syntax from the PowerShell 5.1 alias for Invoke-WebRequest. Anything you remember about -UseBasicParsing is gone.
sortSorts lines of text lexically, not objects. 10 comes before 9 unless you pass -n.
catDumps the whole file to the terminal with no pager. On a large file, use less.
rmImmediate and permanent. No Recycle Bin, no -WhatIf, no undo.
cp dir/ dest/Refuses — "omitting directory". Directories need cp -r.
mkdir a/b/cFails unless a/b already exists. Use mkdir -p.
Command with no outputSuccess. Unix tools stay silent when things go right — no news is good news.
